# PET-VET 🐾

## 📋 Descripción

PET-VET es un proyecto de gestión para una clínica veterinaria.

El objetivo es organizar la información de clientes y facilitar la gestión de los datos mediante una aplicación conectada a una base de datos.

## 🛠️ Tecnologías utilizadas

- **Java:** desarrollo de la aplicación.
- **PostgreSQL:** gestión de la base de datos.
- **JDBC:** conexión entre Java y PostgreSQL.
- **UML:** diseño y representación de la estructura del sistema.

## 📁 Estructura del proyecto

- `Base de datos/`: archivo SQL y diagrama entidad-relación (ERD).
- `Diagram UML/`: código fuente y diagramas UML del diseño.
- `Proyecto PET-VET/`: código Java y biblioteca JDBC necesaria para la conexión con PostgreSQL.

## ⚙️ Funcionalidades actuales

- Consultar registros.
- Insertar nuevos registros.
- Actualizar información existente.
- Eliminar registros.
- Salir del programa desde el menú principal.

El proyecto se encuentra en desarrollo. Se irá ampliando y mejorando a medida que avance mi formación, incorporando nuevas funcionalidades y mejoras en el diseño.
